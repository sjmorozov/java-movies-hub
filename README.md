# MovieHub

Учебный HTTP API-сервис для работы с фильмами.

Проект написан на Java с использованием встроенного `HttpServer`. Данные хранятся в памяти приложения.

## Возможности

- получение списка фильмов;
- добавление фильма;
- получение фильма по id;
- удаление фильма по id;
- фильтрация фильмов по году.

## Эндпоинты

- `GET /movies` — получить список фильмов;
- `POST /movies` — добавить фильм;
- `GET /movies/{id}` — получить фильм по id;
- `DELETE /movies/{id}` — удалить фильм по id;
- `GET /movies?year=1995` — получить фильмы по году.

## Пример POST-запроса

Тело запроса:

`{ "title": "Метрополис", "year": 1927 }`

## Валидация

При добавлении фильма проверяется:

- название не должно быть пустым;
- название не должно быть длиннее 100 символов;
- год должен быть от 1888 до следующего года включительно.

## Ошибки

Сервис возвращает ошибки в формате JSON.

Используемые статусы:

- `400 Bad Request`;
- `404 Not Found`;
- `405 Method Not Allowed`;
- `415 Unsupported Media Type`;
- `422 Unprocessable Entity`.
